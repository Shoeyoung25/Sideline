# Sideline

A two-coach basketball game. Draft five current NBA players each, set your offense and defense in secret before every possession, then watch it play out live and make quick calls. 10 possessions, 5 each.

- `index.html`: page and styles
- `data.js`: player pool (2026-27 per-game stats through Nov 26, 2026) and the playbook
- `engine.js`: possession simulation
- `app.js`: interface and game flow

No build step. Open `index.html`, or serve the folder with GitHub Pages.
